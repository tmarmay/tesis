# Papers de referencia

Listado de los papers usados como fuente de conocimiento para la tesis, con una descripción breve de cada uno.

## General/

- [`Fifty Years of Vehicle Routing.pdf`](General/Fifty%20Years%20of%20Vehicle%20Routing.pdf) — Revisión histórica de cincuenta años de investigación sobre el problema de ruteo de vehículos (VRP), desde sus orígenes hasta las técnicas modernas.
- [`Scheduling-of-Vehicles-from-a-Central-Depot-to-a-Number-of-Delivery-Points-Clarke.pdf`](General/Scheduling-of-Vehicles-from-a-Central-Depot-to-a-Number-of-Delivery-Points-Clarke.pdf) — Paper original de Clarke y Wright que introduce el algoritmo de ahorros (savings algorithm) para programar vehículos desde un depósito central hacia múltiples puntos de entrega.
- [`The Vehicle Routing Problem in Field Logistics - Part II.pdf`](General/The%20Vehicle%20Routing%20Problem%20in%20Field%20Logistics%20-%20Part%20II.pdf) — Modela la planificación y programación de unidades de servicio en operaciones agrícolas de campo como una instancia del VRP con ventanas de tiempo (VRPTW).

## GA/

- [`A-hybrid-genetic-algorithm-for-route-optimization-in-the-bale-collecting-problem.pdf`](GA/A-hybrid-genetic-algorithm-for-route-optimization-in-the-bale-collecting-problem.pdf) — Propone un algoritmo genético híbrido para resolver el problema de recolección de fardos (bale collecting problem), minimizando tiempo improductivo, combustible y distancia recorrida.

## ACO/

- [`Ant-System:-Optimization-by-a-Colony-of-Cooperating-Agents.pdf`](ACO/Ant-System:-Optimization-by-a-Colony-of-Cooperating-Agents.pdf) — Paper fundacional de Dorigo, Maniezzo y Colorni que introduce el Ant System, la base de los algoritmos de optimización por colonia de hormigas (ACO).
- [`Ant Colony Optimisation for Vehicle Routing Problems - From Theory to Applications.pdf`](ACO/Ant%20Colony%20Optimisation%20for%20Vehicle%20Routing%20Problems%20-%20From%20Theory%20to%20Applications.pdf) — Revisión de cómo se aplica ACO al VRP, cubriendo desde los fundamentos teóricos hasta casos de aplicación práctica.
- [`Ant Colony Optimization Algorithm for Multi-Depot Vehicle Routing Problem with Time Windows.pdf`](ACO/Ant%20Colony%20Optimization%20Algorithm%20for%20Multi-Depot%20Vehicle%20Routing%20Problem%20with%20Time%20Windows.pdf) — Aplica ACO al VRP multi-depósito con ventanas de tiempo (MDVRPTW).
- [`Ant Colony Optimization for Multiple Pickup and Multiple Delivery Vehicle Routing Problem with Time Window and Heterogeneous Fleets.pdf`](ACO/Ant%20Colony%20Optimization%20for%20Multiple%20Pickup%20and%20Multiple%20Delivery%20Vehicle%20Routing%20Problem%20with%20Time%20Window%20and%20Heterogeneous%20Fleets.pdf) — Extiende ACO a un VRP con múltiples recogidas y entregas, ventanas de tiempo y flota heterogénea.
- [`A Two-Stage Hybrid Ant Colony Algorithm for Multi-Depot Half-Open Time-Dependent Electric Vehicle Routing Problem.pdf`](ACO/A%20Two-Stage%20Hybrid%20Ant%20Colony%20Algorithm%20for%20Multi-Depot%20Half-Open%20Time-Dependent%20Electric%20Vehicle%20Routing%20Problem.pdf) — Propone un algoritmo híbrido ACO en dos etapas para un VRP multi-depósito, semiabierto, dependiente del tiempo y con vehículos eléctricos.
- [`Optimal-route-planning-of-agricultural-field-operations-using-ant-colony-optimization.pdf`](ACO/Optimal-route-planning-of-agricultural-field-operations-using-ant-colony-optimization.pdf) — Usa ACO para planificar rutas óptimas en operaciones agrícolas de campo.
- [`Solving Vehicle Routing Problem using Ant Colony Optimisation (ACO) Algorithm.pdf`](ACO/Solving%20Vehicle%20Routing%20Problem%20using%20Ant%20Colony%20Optimisation%20(ACO)%20Algorithm.pdf) — Aplicación general del algoritmo ACO para resolver el VRP clásico.
- [`Tackling Dynamic Vehicle Routing Problem with Time Windows by means of Ant Colony System.pdf`](ACO/Tackling%20Dynamic%20Vehicle%20Routing%20Problem%20with%20Time%20Windows%20by%20means%20of%20Ant%20Colony%20System.pdf) — Aborda la variante dinámica del VRP con ventanas de tiempo (DVRPTW) mediante un Ant Colony System.
- [`Vehicle Routing Problem Considering Reconnaissance and Transportation.pdf`](ACO/Vehicle%20Routing%20Problem%20Considering%20Reconnaissance%20and%20Transportation.pdf) — Formula un VRP para movimientos de tropas en tiempo de guerra que combina simultáneamente unidades de reconocimiento y transporte (VRPCRT), resuelto con un modelo MILP y un algoritmo ACO.

## MILP/

- [`MILPBench - A Large-scale Benchmark Test Suite for Mixed Integer Linear Programming Problems.pdf`](MILP/MILPBench%20-%20A%20Large-scale%20Benchmark%20Test%20Suite%20for%20Mixed%20Integer%20Linear%20Programming%20Problems.pdf) — Presenta MILPBench, un benchmark a gran escala de 100.000 instancias de programación lineal entera mixta (MILP) organizadas en 60 clases, con una librería base de 15 métodos de resolución.
- [`On the Vehicle Routing Problem with Time Windows.pdf`](MILP/On%20the%20Vehicle%20Routing%20Problem%20with%20Time%20Windows.pdf) — Estudia formulaciones de programación entera mixta (MILP) para el VRP con ventanas de tiempo.

## NN/

- [`A Variable Neighborhood Search for the Multi-Depot Vehicle Routing Problem with Time Windows.pdf`](NN/A%20Variable%20Neighborhood%20Search%20for%20the%20Multi-Depot%20Vehicle%20Routing%20Problem%20with%20Time%20Windows.pdf) — Aplica una búsqueda de vecindario variable (VNS) al VRP multi-depósito con ventanas de tiempo (MDVRPTW).
- [`Study Vehicle Routing Problem using Nearest Neighbor Algorithm.pdf`](NN/Study%20Vehicle%20Routing%20Problem%20using%20Nearest%20Neighbor%20Algorithm.pdf) — Estudia la aplicación del algoritmo del vecino más cercano (nearest neighbor) como heurística constructiva para el VRP.
